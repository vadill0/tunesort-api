# tunesort-api

REST API (Node.js, Express, MongoDB) that imports a user's Spotify liked songs,
groups them into coherent genre playlists and stores song/album ratings.

> Status: early development. Client repository: `tunesort-web`.

See [docs/SCOPE.md](docs/SCOPE.md).

## Stack
